# Worth It? - Smart Purchase Calculator

A web app that helps you determine if purchases are worth it by comparing one-time costs against recurring alternatives. Now includes an event calendar with AI-powered purchase suggestions!

## Features

- **Purchase Calculator**: Compare products against recurring costs
- **Product Value Calculator**: Evaluate purchases based on usage and quality
- **Saved Calculations**: Keep track of your analyses
- **Wishlist**: Save items for later consideration
- **Event Calendar**: Mark upcoming events
- **AI Suggestions**: Get Claude AI-powered purchase recommendations based on your events


## Usage

1. **Calculator**: Enter product details and compare against alternatives
2. **Calendar**: Click on calendar days to add events
3. **AI Suggestions**: After adding events, click "Generate New Suggestions" to get AI recommendations
4. **Saved Items**: Access your saved calculations and wishlist

## Local Development

Since this uses Vercel serverless functions, you'll need to either:
- Deploy to Vercel for full functionality
- Or modify the code to use a different AI service for local development
